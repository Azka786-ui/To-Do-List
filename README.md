# 📝 To-Do List App

A simple and interactive **To-Do List** application built with **HTML, CSS, and JavaScript**. It helps users organize their daily tasks by allowing them to add and remove tasks through a clean and user-friendly interface.


## 🚀 How to Use

1. Enter a task in the input field.
2. Click the **Add Task** button.
3. Your task will appear in the list.
4. Click **Delete** to remove any task.
